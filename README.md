# Voz extensions

Extensions for [Voz](https://github.com/Joelheile/voz), the local dictation app for the Mac.

- [voz-meeting](voz-meeting): record and transcribe meetings with one hotkey
- [voz-smart-spacing](voz-smart-spacing): add the missing space when you dictate right after existing text
- [voz-autocorrect](voz-autocorrect): fix words Voz keeps mishearing and learn fixes from your corrections

Install one with `voz install <name>`.
